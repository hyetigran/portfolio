# Skip case-study detail pages for v1

The design mockups include a "read case study →" link with no page ever designed for it, and the mockup file's own suggested next step was to build one. We're deliberately not building case-study pages in v1 — project cards link straight to the live project instead (App Store listing, hedgehog.markets, paragonrobotics.com, swaps.app). This trades away the "architecture notes and decisions I'd defend in review" framing from the mockup copy for a much faster v1. The `Project` data shape doesn't preclude adding case studies later.
