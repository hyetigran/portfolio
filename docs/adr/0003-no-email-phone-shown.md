# Omit email and phone from the public site

The mockups and the source resume PDF both display email and phone directly (header, footer, resume sidebar). The live site deliberately omits both — the nav's "contact" link points to a LinkedIn URL (placeholder until supplied) instead. This is a privacy choice for a public-facing site and a deliberate deviation from the mockup and the resume PDF, so a future editor shouldn't "restore" the missing contact fields without checking first.
